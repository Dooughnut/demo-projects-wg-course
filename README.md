# Demo Projects Godot untuk course Godot Intro

## Petunjuk
Download Godot (Bisa langsung dipakai tanpa langkah-langkah installasi)
Gunakan project yang ada di folder 2D seperti `bullet_shower`, `dodge_the_creeps`, `isometric`, `role_playing_game`.
Buka Godot dan import `project.godot` yang berada di folder project yang dipilih.

> [!NOTE]
>
> The performance of Godot in a browser is lower than natively on
> desktop or mobile. For the best performance, consider downloading
> the demos and running them with a native version of the Godot editor.
